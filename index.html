常見問題

自架需要申請 YouTube 或 Spotify 的 API Key 嗎？

完全不需要。專案採用無金鑰爬蟲與動態解析機制，不需繁瑣的金鑰設定或費用即可運作。

機器人重啟或維護時，播放清單與進度會遺失嗎？

不會。系統內建狀態快照持久化機制，伺服器重啟或更新時自動凍結進度、音量、等化器與待播隊列，重啟完畢後自動重新進房並接續播放。

遇到開頭有廢話、長對白或口播廣告的歌曲怎麼辦？

內建 SponsorBlock 智慧前奏跳轉，自動過濾非音樂性質的開頭前置段落，一秒直奔核心歌曲。

播放清單結束後會停止嗎？

不會。清單播完後會自動無縫銜接官方演算法推薦曲目，亦可使用 /autoleave 指令自由切換 24/7 常駐掛台模式。

為什麼建議自行部署？

官方主機架設在台灣，跨國連線時可能因物理距離產生延遲卡頓。自行部署可享有專屬頻寬、獨立運算資源與熱重載彈性。

支援哪些語言？

支援繁體中文、簡體中文、英文與日文，會依伺服器設定自動切換語言，亦可透過 /language 指令手動指定。
